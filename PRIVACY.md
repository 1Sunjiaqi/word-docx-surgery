# Privacy

The `word-docx-surgery` plugin runs as local instructions and Python scripts. The
project does not operate a remote service, upload documents, or collect telemetry.

Documents, extracted text, render outputs, and verification artifacts are processed
on the user's machine and remain under the user's control. The repository does not
contain user documents or private verification data; its self-test creates synthetic
fixtures in a temporary directory.

The host application may process prompts, files, or command output under its own
privacy policy. That host-level processing is outside this project.

Questions and privacy issues can be reported at:
https://github.com/1Sunjiaqi/word-docx-surgery/issues
