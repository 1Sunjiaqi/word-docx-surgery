# Word 重存噪声：候选件被 Word 打开保存过之后

闸门一（`docx_ledger.py`）按**原始字节**比较部件，这是故意的最大灵敏度，不要改。
代价是：候选件只要被 Word 打开并保存过一次，就会报出一大片"改动"，而其中绝大多数
是 Word 自己的写法，不是人改的。

## 1 一次真实交付里的实测数字

同一对文件（我的产出 → 人在 Word 里看过、改过、保存过）：

| 层面 | 闸门一报告 | 语义层判定 |
|---|---|---|
| 部件 | 22 处（不含 `word/document.xml`，它被 `GATE_IGNORED_PARTS` 排除） | 字节变化 23 个 = **15 个纯重存噪声** + 3 个元数据 + 5 个真实 |
| 批注 | 6 处 | 真实（批注确实被删/被换人） |
| 正文 | 20 处 | **8 处真实改动** |
| 合计 | **48 处** | 真实改动 8 处正文 + 4 个批注部件 |

结论：**48 处报告里，真正需要解释的只有十几处**。没有这一层，白名单就没法写——
你不可能为 Word 自己重排的 22 个部件写白名单。

## 2 噪声清单（每一条都是实测到的）

| 类别 | Word 干了什么 | 归一方式 |
|---|---|---|
| `w:rsid*` | 每次保存给段落/run 挂新的修订 id | 去掉属性 |
| `w14:paraId` / `w14:textId` | 重新生成；页眉页脚里也会重生 | 去掉属性 |
| `xml:space` | 按需增删（`<w:t> </w:t>` ↔ `<w:t xml:space="preserve"> </w:t>`） | 去掉属性 |
| `w:lastRenderedPageBreak` | 重新分页后写进 run | 去掉元素 |
| **run 拆分/合并** | 在分页处把一句话拆成两个 rPr 相同的 run；也会把相同 rPr 的相邻 run 合并，并把文字在两个 `w:t` 之间重新切分 | 合并相邻同 rPr 的 `w:r`；合并同一 run 内相邻的 `w:t` |
| `w:bookmarkStart/End` | id 整体重编号，元素顺序也会变 | 去掉元素，只比较**书签名多重集** |
| 命名空间声明 | 根节点上增删 `xmlns:w16se`、`xmlns:w16sdtfl` 之类的声明 | 按 Clark 名（`{uri}local`）比较，与前缀/声明无关 |

再举两个"看着像噪声、其实要报出来"的：

| 现象 | 为什么必须报 |
|---|---|
| 域被改写成 `w:fldSimple` | XML 形状变了（同样是 `REF` 域，缓存值可能一起变），要人判断 |
| 图片/OLE 对象的 extent 动了 0.3pt | 是真实的几何改动，只是小；渲染像素能看出来 |

## 3 工具

```bash
python scripts/docx_semantic_diff.py 基线.docx 候选.docx
python scripts/docx_semantic_diff.py 基线.docx 候选.docx --quiet --json 语义.json
python scripts/docx_semantic_diff.py 基线.docx 候选.docx --max-real 0   # 断言"只是重存"
```

- 退出码：`0` 通过 / `1` 真实改动超过 `--max-real` / `2` 用法或读取失败。
- `--json` 里有 `raw_parts_changed`（字节层面变了几处）、`noise_parts`、`real_parts`、
  `meta_parts`、`body_real_changes`、`real_total`、`anchor_mode`。
- 元数据部件（`docProps/*`、`word/settings.xml`）Word 每次保存都会写，单独列出、
  **不计入** `real_total`，但它们照样打印出来，不会被藏起来。

## 4 用法定位（别用错）

- 它是**闸门一的补充，不是替代**。判断"有没有越界"永远以闸门一为准：
  闸门一按字节判等，最不容易漏；语义层只是把噪声摘出来，好让白名单可写。
- 收工顺序：**先闸门一（看全量字节变化）→ 再本脚本（摘噪声、定位真实改动）→
  白名单只覆盖真实改动**。若先跑语义层再写白名单，等于用"我自己的归一规则"给自己发通行证。
- 只在候选件确实经过 Word 时才有意义。两边都是你自己脚本产出的，"噪声"通常为 0，
  此时两个工具应当给出同样的结论；**不一致就说明归一规则吃掉了真实改动**，要查。

## 5 自检

`scripts/selftest.py` 的 H 组把这套规则固定成断言：

- H1：灌入 7 类重存写法差异 → 语义层报 0 处真实改动；
- H2：同一对文件在字节层面确实变了（证明 H1 不是空断言）；
- H3：噪声 + 1 处改字 → 只报那一处，并定位到具体单元格；
- H4：把 `--max-real` 调到实际改动数 → 退出码 0（阈值双向有效）。
