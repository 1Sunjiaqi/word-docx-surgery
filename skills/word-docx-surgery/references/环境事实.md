# 运行环境与兼容性

这套工具分成“纯 OOXML 操作”和“桌面 Word 渲染”两层。

## 1 核心层

以下脚本只依赖 Python 3.11+ 标准库：

- `docx_textconv.py`
- `docx_ledger.py`
- `docx_semantic_diff.py`
- `docx_min_edit.py`
- `docx_fill.py`
- `make_baseline.py`
- `verify_readonly.py`
- `selftest.py`

它们负责解包、比较、生成改动清单、局部修改和只读基线，不要求安装 Word，也不要求
`python-docx` 或 `lxml`。核心自检可以在没有 Office 的环境中运行：

```bash
python scripts/selftest.py
```

## 2 桌面 Word 层

以下能力需要 Windows、桌面版 Microsoft Word 和 `pywin32`：

- `render_qa.py`：让 Word 更新域、目录和分页，再导出 PDF。
- `doc_to_docx.py`：通过 Word COM 把二进制 `.doc` 另存为 `.docx`。

`render_qa.py` 还需要至少一种 PDF 光栅化方式：

- `pdftoppm`：来自 Poppler；部分 Codex 运行时已内置。
- `pypdfium2`：可选的 Python 依赖。

`Pillow` 仅用于生成页面联系表。没有它时，逐页 PNG 和 `manifest.json` 仍然可以生成。

安装可选渲染依赖：

```bash
python -m pip install -r requirements-render.txt
```

Word 版本、字体和语言包会影响真实分页。换机器后先运行核心自检，再用一份不含敏感信息的
合成文档跑一次完整渲染。

### 2.1 拿不到桌面 Word 时的替代链路（有两个已知假象）

只有在确实没有桌面 Word 时才退回 LibreOffice 之类的替代渲染器，而且必须知道它会在两处骗人：

1. **不认 `STYLEREF` 域。** 题注里的 `表 ⟦STYLEREF 1 \s⟧-1` 会被渲染成
   `Error: Reference source not found`。于是"题注显示对不对"这一项在预览里**判不了**，
   只能说明"在 Word 里正常"。第 4、5、6、7、8 章的题注都长这样，别把它当成内容错误去"修"。
2. **`cantSplit` 行在页边界放不下时会整行丢掉。** 用"这一页有几行"核对续表是否填满会被骗；
   改成"页面上最后一条墨迹距页面下沿多少像素"来判断填满程度。

替代渲染给出的页数只能当提示值。凡是要下"页数对了、分页对了"的结论，仍要在桌面 Word 里复看。

## 3 必须遵守的实现约束

### 3.1 域不会被普通库算出来

目录、题注、页码和交叉引用等域不会由普通 Python 库重新计算。需要真实页数时，让 Word
打开文档并执行：

```text
Fields.Update()
TablesOfContents.Update()
Repaginate()
```

`render_qa.py` 默认执行这些步骤；跳过字段更新后，页数只能视为提示值。

### 3.2 ElementTree 序列化必须保留命名空间

用 `xml.etree.ElementTree` 解析和重写 `word/document.xml` 时，ET 可能只保留实际用到的
命名空间，导致根节点上的 `mc:Ignorable` 引用未声明前缀，Word 会判定文件损坏。

修复方式是序列化后把原根节点中缺失的 `xmlns:*` 声明补回。
`docx_fill.py` 的 `preserve_root_namespaces()` 已处理这一情况。

判断 OOXML 改动是否合法，不能只靠库能否读取；必须让目标版本的 Word 实际打开。

### 3.3 进程清理只处理自己启动的实例

Word COM 在受限环境或异常文档上可能长时间不返回。先正常等待；需要停止时，只结束当前
任务启动的 PID，不要按 `python.exe` 或 `WINWORD.EXE` 等进程名批量终止。

### 3.4 不要假定固定的解释器命令

不同系统可能使用 `python`、`python3`、`py -3.11` 或虚拟环境路径。文档和任务卡应明确
当前项目使用哪个解释器，不要假定裸 `python` 在所有机器上都指向同一环境。

## 4 已知失败模式

| 现象 | 原因 | 处理 |
|---|---|---|
| Word 报文件损坏 | ET 丢失根节点命名空间声明 | 补回原始 `xmlns:*`，再用 Word 打开验证 |
| `docx_min_edit.py` 报未找到连续文本 | 目标文本被 Word 拆成多个 run | 先看规范文本，改用段级定位 |
| PDF 页数与 Word 不一致 | 域未更新或未重新分页 | 执行字段更新和重新分页后再导出 |
| 等长部件改动被漏掉 | 只比较文件长度 | 同时比较大小和内容哈希 |
| 多 run 段落出现字形错位 | 段落被拍平成单 run | 段内编辑保留原 run 切分 |
| 预览里题注显示 `Error: Reference source not found` | 替代渲染器不认 `STYLEREF` 域 | 到 Word 里复看；**不要**为了迁就预览去改文档 |
| 按行数核对续表填不满/少一行 | 替代渲染器把放不下的 `cantSplit` 整行丢掉 | 改成量"页面最后一条墨迹距下沿的像素" |
| 闸门一报出几十处改动，其中大半没人动过 | 候选件被 Word 打开保存过，Word 重写了自己的写法 | 跑 `docx_semantic_diff.py`，见 `Word重存噪声.md` |

## 5 脚本分工

| 脚本 | 作用 |
|---|---|
| `scripts/docx_textconv.py` | `.docx` -> 可逐行比较的规范化文本；也可作为 git textconv 驱动 |
| `scripts/docx_ledger.py` | 闸门一：改动清单 + 白名单断言（部件 / 批注 / 正文） |
| `scripts/docx_semantic_diff.py` | 语义层：把 Word 重存噪声与真实改动分开；`--max-real` 可当断言用 |
| `scripts/render_qa.py` | 闸门二：副本 -> Word 更新域 -> PDF -> 逐页 PNG -> 联系表 + manifest |
| `scripts/docx_min_edit.py` | 定位式最小替换（`--occurrence N`） |
| `scripts/docx_fill.py` | 按规格填单元格/段落（保留 pPr，按需克隆段，可重置列表编号） |
| `scripts/doc_to_docx.py` | `.doc -> .docx`（走 Word COM） |
| `scripts/make_baseline.py` | 开工前给目录生成只读基线（默认拒绝覆盖） |
| `scripts/verify_readonly.py` | 只读自检；`--ack` 显式登记外部改动 |
| `scripts/selftest.py` | 在临时目录验证闸门能力（18 项断言，A~H 组） |
